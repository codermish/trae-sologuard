# SoloGuard

SoloGuard is an AI-powered code reliability and hallucination analysis tool built using TRAE SOLO’s multi-agent system. It evaluates code generated by SOLO Builder and SOLO Coder to ensure correctness, stability, and safety.

## Overview

SoloGuard automatically analyzes frontend and backend files for:

* missing variables or functions
* incorrect imports
* unsupported or fictional APIs
* unsafe logic changes
* removed error-handling
* UI component failures
* backend functional errors
* unused code or inconsistent naming

It produces:

* a reliability score (0–100)
* hallucination list
* risk report
* diff summary
* a safe auto-generated patch

## Multi-Agent Workflow

1. SOLO Builder generates code
2. SOLO Coder updates or modifies files
3. SoloGuard is automatically called with oldCode + newCode
4. SoloGuard analyzes and returns risks + patch
5. Builder/Coder applies fixes until code is safe

## Tech Stack

**Frontend:** TypeScript, JavaScript, Lynx, Tailwind, Zustand, React Router, Axios
**Backend:** Node.js, Express, TypeScript, Prisma ORM, PostgreSQL
**Tools:** Vite, Concurrently, Multer, JWT, Supabase, Stripe, Grafana

## Tiny Test App

A minimal one-page Lynx application is used to test SoloGuard:

* renders “Hello, World”
* button updates label text
* backend `/api/ping` endpoint
* includes intentional issues for SoloGuard to detect
